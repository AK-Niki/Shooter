# 🧠 ShooterGame на Jetpack Compose

Игра-шутер, написанная на Kotlin с использованием Jetpack Compose. Игрок управляет персонажем, который отстреливается от волн врагов: обычных врагов, усиленных и боссов. Каждые 100 очков — бонус к здоровью. Игра заканчивается, когда у игрока заканчиваются жизни.

## 🧩 Особенности проекта

- Jetpack Compose
- Структурированный код с ViewModel
- Плавная анимация и стабильный FPS
- Разные типы врагов (1, 2, 3 HP)
- Волны врагов каждые 200 очков
- +1 HP каждые 100 очков
- SoundPool для звуков выстрелов, попаданий и бонусов
- Полноэкранный фон без черных полос
- Архитектура с разделением на: UI, ViewModel, Model, Utils


## 🚀 Как запустить

1. Клонируй репозиторий

2. Открой проект в **Android Studio**.

3. Убедись, что установлены зависимости:
- Kotlin
- Jetpack Compose
- lifecycle-viewmodel
- SoundPool

4. Запусти на эмуляторе или физическом устройстве (Android 7.0+).
